# E1 해석 · 두 모델 비교 (교육생 B · 2026-11-02 측정)

질문: "LLM pipeline과 AI Agent의 차이를 신입 개발자에게 설명해 주세요."
System: "당신은 신입 개발자를 돕는 선배 엔지니어입니다. 한국어로 3문장 이내로 답합니다."
환경: MacBook(Apple Silicon) · Claude Code 2.1.316 · claude-agent-sdk 0.2.176 · LM Studio · Gemma 4 E4B

## 해석

1. 같은 질문에서 추론 토큰이 Haiku 0~86, Gemma 380~676으로 실행마다 크게 흔들렸다. 비용·지연 추정은 1회가 아니라 여러 번 잰 범위로 해야 한다.
2. Haiku는 SDK system prompt 631토큰을 1시간 캐시로 써서 첫 호출이 $0.000412, 이후 $0.000246~0.000296(약 30~40% 절감)이었다. `total_cost_usd`에는 `usage`에 보이지 않는 부가 호출 몫이 매번 포함된다.
3. 1,000건 순차 처리 시 Haiku는 약 $0.25~0.41에 약 1시간, Gemma는 API 비용 0에 3~5시간이다. Gemma의 답 품질은 10/29 오답, 11/2 정답으로 달라 eval 없이 판단할 수 없다.
